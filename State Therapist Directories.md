# State Therapist Directories

> Directories of therapists in one U.S. state, run by state professional associations, state agencies, or independent sites. National directories are in the [main list](README.md#directories).

Association directories list members only. State-run finders mostly list public or state-certified agencies, not private practices. Links marked † were found through search results on the owner's own site but could not be opened directly to confirm; check them before relying on them.
